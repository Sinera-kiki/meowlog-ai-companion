# Contributing

MeowLog is currently maintained as a portfolio project. Issues and focused pull requests are welcome.

## Development

1. Fork and clone the repository.
2. Copy `.env.example` to `.env`.
3. Run `docker compose up --build`.
4. Before submitting, run the frontend build and backend tests.

## Pull requests

- Keep one product problem per PR.
- Include before/after screenshots for visual changes.
- Add or update tests for backend behavior.
- Never commit API keys, `.env`, database dumps, or personal chat data.
