# MeowLog 游戏与经济设计

## 核心循环

```text
互动 → 完成任务 → 获得叶子币 → 购买服饰 → 搭配收藏
  ↘ 提升亲密度 → 解锁新服饰 / 探险内容 ↗
```

## 新手资产

玩家领养完成后获得：

- 30 叶子币
- 赤豆围巾
- 林间雏菊
- 苔藓小斗篷
- 野餐格围裙

这样可以在首次进入时体验配饰和服装双槽搭配，同时保留商店成长空间。

## 货币来源

| 来源 | 每日/单次奖励 | 设计目的 |
| --- | ---: | --- |
| 每日签到 | 12—24 | 建立轻量回访习惯 |
| 喂食任务 | 8 | 引导基础状态维护 |
| 抚摸任务 | 10 | 引导亲密互动 |
| 玩耍任务 | 12 | 展示动态反馈 |
| 聊天任务 | 15 | 进入 AI 核心体验 |
| 探险归来 | 8—18 | 放置等待与随机惊喜 |

日常任务总计 45 叶子币，配合签到后，玩家通常可以每天获得至少一件普通单品，稀有单品需要积累。

## 商店定价

| 档位 | 价格 | 例子 |
| --- | ---: | --- |
| 新手 | 免费 | 围巾、斗篷 |
| 普通 | 24—38 | 雏菊、围裙、挎包 |
| 进阶 | 52—68 | 睡帽、雨衣、针织衫、领结 |
| 稀有 | 88—108 | 莓果礼服、神秘纸箱、月光睡袍 |

## 亲密等级

每 10 点亲密度提升 1 级。互动和探险均能增加亲密度，等级用于控制服饰与未来地图解锁。

## 探险

探险包含：

1. 随机目的地
2. 返回倒计时
3. 性格相关的 AI 手帐
4. 战利品名称和明信片主题
5. 叶子币与亲密度奖励

演示环境默认 45 秒完成，正式环境可提高到小时级。

## 防止体验断点

- 无 AI Key 时使用演示回复
- 新手直接获得双槽穿搭
- 任务明确展示进度和可领取状态
- 商店直接说明三种货币来源
- 购买、领奖、探险归来均提供声音、震动和 Toast 反馈
