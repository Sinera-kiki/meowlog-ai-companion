# MeowLog 产品案例

## 1. 背景

虚拟宠物游戏依赖养成与收集维持留存，AI 陪伴产品依赖对话提供情绪价值。前者缺乏真正理解，后者缺乏可持续玩法。MeowLog 的目标是验证：**当 AI 角色拥有生活状态、长期记忆和游戏目标时，用户是否更容易建立持续关系。**

## 2. 目标用户

- 喜欢猫咪、治愈系内容和轻量放置游戏的年轻用户
- 学习或工作压力较大，希望获得低负担陪伴的用户
- 不想承担真实养宠成本，但喜欢养成与装扮的用户

## 3. 核心问题

1. AI 对话每次像重新认识，缺少连续关系。
2. 纯聊天缺乏长期目标，打开频率难以维持。
3. 虚拟宠物的反馈高度脚本化，缺少个体差异。

## 4. 产品假设

- 用人格标签约束语言与行为，可以提高角色一致性。
- 将重要对话萃取为长期记忆，可以增强“它真的记得我”的感受。
- 用任务、探险、奖励和换装构建轻循环，可以降低聊天压力并提升回访动机。

## 5. MVP 范围

### 必做

- 领养与人格选择
- 状态、互动、亲密度
- AI 对话与长期记忆
- 探险、手帐、奖励
- 每日任务、货币、商店、换装
- 移动端公网 Demo

### 暂不做

- 多宠物社交
- 玩家交易
- 重度战斗
- 商业支付
- 复杂 UGC 编辑器

## 6. 核心用户旅程

```text
首次进入 → 领养并选择人格 → 完成首次互动 → 获得新手衣橱
→ 每日陪伴任务 → 领取叶子币 → 商店购买 → 双槽换装
→ 派遣探险 → 收到手帐和战利品 → 分享心事 → 后续记忆召回
```

## 7. 产品指标（未来埋点）

| 指标 | 含义 |
| --- | --- |
| 领养完成率 | 初次体验是否顺畅 |
| 首日三次互动完成率 | 核心动作是否有吸引力 |
| 探险发起/领取率 | 放置循环是否成立 |
| D1 / D7 留存 | 关系与任务是否形成回访 |
| 每周记忆召回次数 | AI 长期记忆是否真正发挥作用 |
| 商店购买与换装率 | 成长经济是否驱动目标 |

## 8. 关键取舍

- 优先做完整垂直闭环，而不是堆大量地图和服饰。
- 使用 Lazy Tick 模拟离线生活，避免为 MVP 引入复杂任务队列。
- 允许无 Key 演示，保障作品可访问；真实 AI 作为增强能力。
- 游客 ID 便于试玩，但明确不等同于正式账号安全体系。
